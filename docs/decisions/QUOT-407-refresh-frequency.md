# 刷新频率与样本量验收口径（QUOT-407，2026-11-05 老板拍板）

- 日期：2026-11-05
- 基线：TickHub-CN `main@8ecb8dc`（v1.1.0）；LadderStock PR #111
- 关系：本文件替换 `QUOT-407-endpoint-breaker-semantics.md` §1.1 中「每档 ≥10 分钟 **且** ≥60 次」的样本量条件；熔断/计数口径仍以该文件为准

## 1. 刷新频率

| 项 | 定论 |
| --- | --- |
| 当前档位 | **15s**（默认） |
| 可选档位 | 15s / 30s / 60s，图表下拉选择 |
| 秒级（1s / 5s） | **暂缓**，配置保留、默认隐藏；商业化 IP 代理池上线后启用 |
| 商业池接入 | `provider: pool/commercial/direct` 可插拔，`commercial_url` 填链接即可；实现保留在代码中 |
| 配置形态 | Vite env `VITE_LDST_CHART_REFRESH_SEC`（初始档位）、`VITE_LDST_CHART_REFRESH_SECOND_LEVEL`（放开秒级）；本机选择落 `localStorage['ldst.chart.refreshSec']` |

## 2. 样本量验收

`次数 = 600 秒 ÷ 档位秒数`（向上取整），运行时长一律 ≥600s：

| 档位 | 有效样本下限 | 时长下限 |
| --- | --- | --- |
| 15s | 40 | 600s |
| 30s | 20 | 600s |
| 60s | 10 | 600s |
| 秒级（启用后） | 60 | 600s |

只计真实到达上游的请求；缓存命中、闸门拒绝、熔断拒绝都不计样本（与熔断定论 §1.1 计数口径一致）。被上游拒绝的请求计入**失败**并标注原因。

## 3. 出口封锁的处置

`push2` 族对当前云机房出口的主机级封锁记为**已知限制**，不阻塞本轮验收：在当前出口按 15s 档继续采集，拒绝请求计失败；结论中必须写明「有效样本不足系出口所致，不是上游速率上限」。不因此调整闸门常量。

## 4. 已知落差（必须随口径一起传达）

界面 15s 刷新不等于上游 15s 新鲜度：TickHub `stock_fund_flow_batch` 缓存 TTL=60s、端点族闸门 25s/60s≤3，15s 刷新多数命中缓存。要真正 15s 粒度需下调 TTL 与闸门常量，属单独审批项。
